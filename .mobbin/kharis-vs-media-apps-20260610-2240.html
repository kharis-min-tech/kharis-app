Takeaway
Strong skeleton. Structure already matches the category leaders.
Adopt: real artwork density — posters sell taps.
Adopt: editorial rail titles ("Made for you", "New this week").
Adopt: one daily anchor — our reading pill can grow into this.
Adopt: full-bleed hero for the latest sermon on Sundays.
1

Real artwork on Continue Listening

Netflix and TIDAL never show flat gradient tiles. We already have real SoundCloud artwork URLs in the dataset — render them on the rail tiles instead of gradients.

2

Sunday hero mode

Apple TV leads with one cinematic title. When a new sermon drops, promote the Latest Message card to a full-bleed hero with the YouTube still as background.

3

Editorial rail naming

TIDAL's rails read like a person curated them. Rename ours: "Continue Listening" stays, add "New this week" and "Start here" for first-time visitors.
